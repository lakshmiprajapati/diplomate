# DiploMate — Requirements

## 1. Product

**Name:** DiploMate

**Tagline:** Your Mate for What's Next.

**Description:**  
A career and opportunity hub designed for diploma students.

## 2. Target Users

Primary users are diploma students who are looking for:

- Jobs
- Internships
- Scholarships
- Further education opportunities

## 3. Core Problem

Career and educational opportunities for diploma students are often scattered across different platforms and sources.

DiploMate aims to provide a centralized and structured way to discover these opportunities.

## 4. MVP Features

### Student

- Registration
- Login
- Browse opportunities
- Search opportunities
- Filter opportunities
- View opportunity details
- Save opportunities
- Manage basic profile

### Admin

- Admin login
- Create opportunities
- Edit opportunities
- Delete opportunities
- Manage opportunities
